Open `index.html` in Chrome or Edge. This static site needs no build tools.

## Publish free
1. Visit https://app.netlify.com/drop and sign in.
2. Drag the **unzipped** `pmns-personal-3d-website` folder into Netlify Drop.
3. Open the resulting HTTPS URL and test navigation, mobile layout and email inquiry.
4. Update canonical/og URL in index.html, and the domain placeholders in sitemap.xml and robots.txt to the actual live URL; redeploy.
5. Verify your URL at https://search.google.com/search-console and https://www.bing.com/webmasters and submit `sitemap.xml`. Indexing is at the engines' discretion.
